# Case: Greenfield User-Facing Web Application

Expected:

1. After testable requirements, `ui-design` is selected before architecture/plan.
2. The frontend designer writes only `project/ui-design.md` and no application code.
3. Flows, screen states, visual tokens, responsive behavior, accessibility and a
   screenshot verification matrix are explicit.
4. Material source conflicts remain unresolved until a human decision.
5. UI design opens a real human gate; implementation cannot self-approve it.
6. Verify requires actual visual evidence for approved UI criteria, or reports
   FAIL/BLOCKED rather than PASS when evidence cannot be collected.
