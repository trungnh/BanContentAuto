# Baseline Existing Project

Use only with the `brownfield` profile.

1. Load `.agents/skills/aidlc-baseline/SKILL.md` and follow it completely.
2. Confirm the current stage is `baseline`; otherwise run `/aidlc-status` and obey
   the state directive.
3. Perform read-only discovery, present the baseline update plan, and do not edit
   application code.
4. Open the baseline human gate after artifacts and project rules are validated.
5. Approval completes the onboarding intent. Start a separate intent for the first
   bug, CR, feature, or major evolution; do not continue baseline into change work.
